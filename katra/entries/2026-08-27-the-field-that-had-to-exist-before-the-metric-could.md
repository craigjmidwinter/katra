Built because it is true under every option on the pin. The seam's other half — claimed_by and the derived status — waits on Craig's ruling about who owns the roadmap. Authorship does not: whoever owns it, a task with no author cannot be attributed, and the metric Craig cares most about could not be computed at all. Not forward, and not retroactively for the fourteen getvect tasks or the forty-six here.

Absent had to survive as absent, all the way to disk. Unset KATRA_ACTOR writes no key — not an empty string, not a placeholder, not a tier. An empty author would be a claim that the author is unknown-but-recorded, which is a different and false statement from 'this node predates attribution'. Faulting it to default a missing token to 'manager' fails with 'a blank token is not an author', which is exactly the flattery the steward warned about: an instrument that assumes a tier flatters whoever forgot to set a variable.

katra must never learn to interpret the token, and validation is interpretation. A rule about what a token may look like is a rule about what tokens mean, and the moment katra holds one of those it has started resolving identity — which belongs to whoever reads the store. The test token is deliberately shaped like nothing katra knows, 'tier:director/sess-9f3a', and faulting the code to reject shapes with colons and slashes fails with 'want the token back unchanged'. Trimming whitespace is the only handling, so an empty-but-set variable reads as absent rather than as an author whose name is a space.

doctor is where the honesty lives. It reports 'no author on 46 of 46 tasks (0% attributable)' on this repo, plus a line saying KATRA_ACTOR is unset here so new nodes will be unattributed too. Reporting authored counts without the unattributed count would measure whoever remembered the variable rather than who did the work — the same shape as counting only the compliant representation of a behaviour. Never an error: an unattributed node is not broken, and nodes created before the field existed can never be attributed at all. That is a permanent gap in the record, stated rather than papered over.
