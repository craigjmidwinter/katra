---
title: Embeds get no same-origin opt-in
date: "2026-11-03"
time: "17:24:59"
type: decision
status: accepted
---

The proposal offered a per-embed key restoring allow-same-origin for trusted cases. Rejected: the key would live in the committed markdown the sandbox defends against, so an attacker could set it, and katra's own 8 embeds need none of it. The sandbox is exactly allow-scripts allow-pointer-lock. Security owner's checklist asks for the same.
